# Diffie-Hellmann key exchange

Tiny no-dependency implementation of [Diffie-Hellmann key exchange](https://en.wikipedia.org/wiki/Diffie%E2%80%93Hellman_key_exchange) in python

## How to run

- Install [`uv`](https://docs.astral.sh/uv)
- run `uv sync`
- run `uv run main.py`


Note: base python's `pow()` function is awesome, it can do modulo of large powers very efficiently!
